Jone Paniagua DAW I Entornos de Desarrollo 

## 📌 Descripción
Proyecto de práctica para aprender control de versiones con Git y GitHub, usando ramas, commits y resolución de conflictos.

---

## 🌿 Ramas del proyecto

- `master` → versión principal del proyecto
- `optimizar-nomenclatura` → mejoras en nombres y botones
- `optimizar-boton-anadir` → mejoras en la interfaz

---

## ⚙️ Flujo de trabajo

1. Crear rama:
   git switch -c nombre-rama

2. Añadir cambios:
   git add .
   git commit -m "mensaje"

3. Subir rama:
   git push origin nombre-rama

4. Crear Pull Request en GitHub

---

## 🔄 Conflictos

Los conflictos aparecen cuando dos ramas modifican el mismo archivo.

Se resuelven:
- en GitHub (web editor)
- o en VS Code

---

## 🚀 Objetivo

Aprender a trabajar con Git, control de versiones y colaboración en proyectos de software.
